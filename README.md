🛍️ NovaCart – E-commerce Shopping Cart

NovaCart is a responsive e-commerce web application built using React.js. It allows users to explore products, add items to their cart, manage quantities, and calculate the total price.

🚀 Features

- Fetch and display products using an API
- Add products to cart
- Increase and decrease product quantity
- Remove products from cart
- Automatic total price calculation
- Responsive design for mobile and desktop
- Clean and user-friendly interface

🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- REST API
- Git & GitHub

💻 Run Locally

1. Clone the repository:
   
   git clone YOUR_REPOSITORY_URL

2. Navigate to the project folder:
   
   cd NovaCart

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev
